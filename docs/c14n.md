# Canonical XML

`yaxml::c14n` implements [Canonical XML 1.0](https://www.w3.org/TR/xml-c14n),
[Canonical XML 1.1](https://www.w3.org/TR/xml-c14n11) and
[Exclusive XML Canonicalization 1.0](https://www.w3.org/TR/xml-exc-c14n) over
the borrowed `Document` and the `OwnedDocument`. Where libxml2 2.15.4 `c14n.c`
departs from the recommendations, yaxml follows libxml2.

```rust
use yaxml::OwnedDocument;
use yaxml::c14n::{self, Mode, Options};
use yaxml::xpath::{Context, XPath};

let document = OwnedDocument::parse("<r xmlns:p='urn:p'><p:e b='2' a='1'/></r>")?;
let context = Context::new().with_namespace("p", "urn:p");
let nodes = XPath::compile("(//. | //@* | //namespace::*)[ancestor-or-self::p:e]")?
    .select_nodes(&document, document.root().id(), &context)?;
let options = Options { nodes: Some(&nodes), ..Options::new(Mode::Exclusive10) };
assert_eq!(c14n::to_string(&document, &options)?, r#"<p:e xmlns:p="urn:p" a="1" b="2"></p:e>"#);
# Ok::<(), Box<dyn std::error::Error>>(())
```

## Contract

- `Options` carries the arguments of `xmlC14NDocSaveTo`: `Mode` (`C14n10`,
  `C14n11`, `Exclusive10`), `with_comments`, an optional XPath node-set
  (`None` renders the whole document) and the exclusive InclusiveNamespaces
  PrefixList (`#default` or `""` for the default namespace).
- `write` streams UTF-8 to a `std::io::Write` through a `BufWriter` and
  flushes it; `to_string` returns the bytes `xmlC14NDocDumpMemory` would. On
  error, output already written to the sink stays there.
- Traversal is iterative; memory is proportional to depth plus in-scope
  namespace declarations. A node-set is hashed once; namespace nodes match by
  (element, prefix), as `xmlXPathNodeSetContains` does.
- Errors: `RelativeNamespace` (`XML_C14N_RELATIVE_NAMESPACE`) for a namespace
  URI without a scheme, and `InvalidUri` (`XML_ERR_INVALID_URI`) for one that
  does not parse or for an `xml:base` the 1.1 fixup cannot resolve. libxml2
  checks every element, in all three modes, even outside the node-set.

## libxml2 behavior kept

- Namespace URIs are written unescaped, so `xmlns:p="http://a/?x&amp;y"`
  renders as `xmlns:p="http://a/?x&y"`.
- Attribute nodes in the set render even when their element is not in it, as
  do namespace nodes (in exclusive mode, listed ones). Exclusive mode declares
  a prefix used by a selected attribute when no output ancestor rendered that
  namespace node.
- 1.0 orphans inherit the nearest ancestors' `xml:*` attributes except those
  named like a selected own attribute; the recommendation also excludes
  unselected own attributes.
- 1.1 renders a visible element's own `xml:lang`, `xml:space` and `xml:base`
  whether or not selected, resolves `xml:base` against invisible ancestors with
  `uri::resolve` (appending `/` to a value whose second-last byte is `.`), and
  drops an empty result, so `xml:base=""` disappears even from whole documents.
- Newlines around PIs and comments follow libxml2's position state: when the
  document element is omitted, each outermost visible element acts as the
  document element, so later PIs and comments get a leading newline even
  inside the omitted element.

## Gaps

- No `xmlC14NIsVisibleCallback` hook or `xmlC14NDocSave` file output.

## Verification

`cargo test --test c14n` runs every libxml2 `test/c14n` case with a result
file, with its `.xpath` selection and `.ns` prefix list, from the pinned
source (`YAXML_LIBXML2_SRC` overrides the path; the test skips without it):
documents load their entities through a `FileResolver` rooted beside them,
as `runtest.c`'s `xmlReadFile(..., NOENT)` does. All 73 match byte for
byte (the `xmlns=""` cases need the XPath namespace axis to list the
undeclaration, as `xmlGetNsListSafe` does). The borrowed DOM
must agree with the owned one wherever it parses (it lacks single-byte
encodings). Hand-written cases were recorded from `xmllint --c14n`,
`--c14n11` and `--exc-c14n`; node-set cases follow the recommendations'
examples. The `c14n` fuzz target checks both DOMs agree and that whole-document
output is its own canonical form.
