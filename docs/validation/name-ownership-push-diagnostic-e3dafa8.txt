The original benchmark frame shrinks 0x810 -> 0x7f0; it allocates once per

After outlining, measure_push has 469 base / 462 candidate instructions, with
local frames 0x600 / 0x5f0 plus the same 0x60 save area. Its ordinary no-event
feed instructions retain the same register assignments and parser stack
placement in both variants; differences in the surrounding function concern
frame size, event representation, branch offsets and metadata. Decoder/tokenizer
ordinary instructions remain unchanged. Removing cross-mode caller context
removes this measured ratio gap. This supports caller/codegen-context sensitivity
and contradicts added per-feed semantic work or frame bloat as an explanation.
It does not identify a microarchitectural cause or justify a production hint.
