# yaxml agent notes

Pure-Rust libxml2 2.15.4 rewrite. `#![forbid(unsafe_code)]`; memchr is the only library dep (fuzz-only deps live in `fuzz/`, its own workspace). FFI bindings go in separate crates (docs/bindings.md, owner sign-off needed).

## Layout
- One engine (src/parser.rs, src/tokenizer, src/stream) feeds Reader (slice), PushParser, BufferedReader, TextReader, Document (borrowed DOM), OwnedDocument (arena, `OwnedNodeId`). DTD-free input stays on the plain token loop; DTD stack = src/dtd*.
- `ParseOptions` (src/options.rs) is the single entry for flags (libxml2 `XML_PARSE_*` values), `Limits`, `DecodeLimits`, `base`, `Resolver`. Default = libxml2 default (entity-ref nodes kept, nothing loaded). Unimplemented flags -> `ErrorKind::UnsupportedOption`, never silently ignored.
- Config structs (every `Limits`/`Options`/`ParseOptions`/`EditLimits`/`WriterLimits`/`DecodeLimits`) are `#[non_exhaustive]` with pub fields, `Default` = `const DEFAULT`; outside the crate build via `X::DEFAULT.field(v)` chains (setters from `setters!` in src/setters.rs; list every field there, a missing one fails to compile) or field assignment; no struct literals. tests/defaults.rs pins every default: update it with any default change (docs/bindings.md#configuration-structs).
- Crate-private `Navigate` (src/xpath/tree.rs) is shared by XPath, C14N, valid, relaxng, xsd, pattern, schematron.
- Feature `allocator_api` (Rust 1.100): `OwnedDocument<A = Global>`/`OwnedNode<'d, A>`/`Editor<'d, A>`; nodes+attributes in `allocator::Vec<_, A>` (one clone of `A` each), `parse_in`/`create_in`/`allocator()`. src/allocator.rs is the only cfg switch (off = sealed stand-in, MSRV 1.97, API unchanged). Pool/ids/dtd/errors/scratch stay global. Generic consumers: `Navigate` users + Writer (`save::Walk`); `save::Tree`/`to_vec`/html/xinclude Global-only (generic public `Tree` breaks `Tree::Borrowed(..)` inference). `parse_in` rejects XINCLUDE. Keep new constructors in `impl OwnedDocument` (Global) so `OwnedDocument::parse(..)` infers. Derive Copy/Clone on A-generic views manually (derive adds `A: Copy`).
- relaxng: one `Engine<I>` (src/relaxng.rs: start/flush/text/end/finish) driven by the DOM walk and by `relaxng::Stream` (events; used by `TextReader::relaxng_set_schema`). `Deriver` holds `Arc<Arena>`/`Arc<Tables>` so `Stream` has no lifetime. No subtree buffering (libxml2 FullElement unneeded).
- XSD instance validation is one event engine (src/xsd/validate.rs `Validator`: start/text/end/other); tree `run` and public `xsd::StreamValidator` both feed it. Stream == DOM diagnostics is tested (tests/xsd_stream.rs, suite, fuzz/xsd.rs). `Schema` = `Arc<Compiled>` (crate-private, fields via `schema.data`), so `StreamValidator`, `Validator`, `Engine` and `pattern::StreamMatcher` (`Arc<Stream>`, state split in `Cursor` so no per-event clone) have no lifetime. `TextReader.validators` (dtd + relaxng + xsd) is the one feeding point (`fetch`, `skip_entity`, Doctype -> `set_dtd`, `sync` after every fetched event); `xsd_set_schema`/`xsd_diagnostics`; `is_valid` = any set and none failing.
- DTD validation is one event engine (src/valid/engine.rs `Validator`: start/text/other/flush/end; Glushkov `Model` state per open element, ID set, IDREFs checked when the root ends). Tree `engine::run` walks the tree (EntityRef = `other`: content of EMPTY; Text = flush+text so tree text nodes stay runs) and stable-sorts by a `(element ordinal, phase)` key into xmlValidateDocument preorder, rewording ContentModel; stream (src/valid/stream.rs `StreamValidator`, public) keeps push wording (`Misplaced x`/`Text not allowed`/`Expecting more children`, once per element) and document order. Root start tag is held (`Root`) until `set_dtd`/next event: the stream loads the external subset while reading it, so the DTD is complete only after that event. `set_dtd` copies until the root is checked, then only reports new `dtd.issues` (parser-time NotStandalone etc.). Empty DTD/no DTD in stream = SAX `Validation failed: no DTD found !` (tree validates against an empty DTD: the one stream/tree difference). TextReader `DTDVALID`: source built without it, then `set_flags` with it (loads like libxml2). Stream == tree: tests/valid_stream.rs (+ `--ignored` suites and xmllint differentials), fuzz/valid.rs.
- TextReader: `NOBLANKS` is decided at fetch (`Blanks`/`Kids`: areBlanks incl. the `*space=-2` rule that the DOM `xpath::tree::blanks` shares; `Node.replaced` marks NOENT replacement text, never dropped), so buffered subtrees match the tree; the source never sees the flag (`streaming`). `set_parser_property` = `BufferedReader::set_flags` on a pristine session (resolver kept). Attribute value children (`read_attribute_value`) are `Node.parts`, split from `Budget::kept` taken right after a Start/Empty event (`Attr.position`); no kept form = one text, even empty. libxml2 quirks matched: `IsDefault` false, `Normalization` true, `Standalone` -1/-2/0/1, NodeType 6/9/11/12/13/16/17 never emitted (verified with xmllint --stream --debug; 13 because `xmlNodeGetSpacePreserve(text)` is -1). Rejected, with reasons in docs/textreader.md: CurrentNode/CurrentDoc/Preserve/PreservePattern. Errors are returned (no handlers); `line_number`/`column_number` = parsing point via `source.position()` in a caller `LineIndex`. Differential: tooling/libxml2_textreader.c takes FLAGS; `noblanks_streams_match_xmllint` needs YAXML_XMLLINT.
- Streaming hot path: tokenizer `step` (src/tokenizer.rs) is one memchr step per lexical state (no per-byte calls; a markup prefix classifies all its available bytes in one step); `Stream::advance`/`Tokenizer::advance` are `inline(always)`, token runs append within spare capacity without the checked growth path; plain UTF-8 bypasses the decoder (`Stream::advance`). Stream `ParserState` is `lending_namespaces`: names get placeholder `LENT`, `ParserState::lend` fills them from bindings at delivery, closed scopes unwind at the next `process_token` (`settle`); DTD handover calls `stop_lending`. Perf method/table: docs/benchmarks.md (matched driver + `/usr/bin/time -l` instruction counts under host load). PushParser holds only the session (failure/finish/`max_input_bytes` live in `StreamingSession`). Callbacks are `FnMut(&Event, SourceOrigin)`: `deliver` lends the event by reference (attribute list stays `Attributes::Owned`, capacity recycled via `parser::emptied`); while lending, normalized values go to `ParserState::lent` (boxed on first use: state size taxes every slice-reader construction, 496 B cost tiny reader 9%) with `LENT_VALUE` ("\0") placeholders filled in `lend`/`lend_event` (inline(always)); namespace-declaration values are never lent; `settle` clears. Slice reader: `read_step` dispatches once on `rereads()` to `step::<REREADS>` -> `read_token::<REREADS>` (`process_token` = `read_token::<false>` for every other frontend), so strict parsing compiles without recovery checks; `normalized` is inline (no-change scan), `normalize` out of line; `delimited_body` inline(always) (constant delimiters, no memcmp); `invalid_char` <16 bytes uses a table. Measured dead ends (don't retry): in-place `drive_chunk` below 32 bytes (+6% instr, tails rarely hold a token), scalar loops instead of memchr on short haystacks (+2%), `inline(always)` on `process_token` (-2% instr but +6-11% cycles); cold/`inline(never)` helpers or tail calls for recovery checks without the const generic (LLVM re-spills elsewhere, no gain); `invalid_char` table scan beyond 16 bytes (2.3x worse at 40); SWAR control screen. Never write `Self { a, b: a && c, ..self }` builders: rustc 1.95/1.96 SimplifyComparisonIntegral miscompile (fixed in 1.97, the MSRV; rust-toolchain.toml pins 1.97.0) (rust-lang/rust#158206) drops `a`; check with tooling/simplify_comparison_scan.py. Exact per-feed instruction traces: lldb single-step script in docs/benchmarks.md method. rustc 1.97 emits v0 symbols (`_RNv...`): set lldb breakpoints by `nm` address, not legacy `_ZN` names. Sixth series (docs/benchmarks.md): 63/65, losses mixed/namespaces push/7; DTD documents ~3x libxml2 instructions (per-reference re-tokenizing of replacement text, SipHash tables), no single hot spot.
- Attribute entity refs without NOENT (libxml2 attr children): `dtd_tag::kept_form` -> `PreparedAttribute.kept` -> `Budget::kept()` (last start tag, by final attribute position; DOM builders drain it) -> sorted side tables `Document.kept` / `OwnedDocument.kept` (allocator Vec, pool ranges); empty = zero cost. Public `unexpanded_attribute(pos)`; `save` (`Walk::kept_form`) and yaxmllint `--xpath` write it; `attributes()` values stay substituted (XPath/valid/C14N). ATTLIST defaults carry `StoredDefault::Value.kept` (DTDATTR). Writer writes substituted. Owned `set_attribute_value` drops the form.
- Owned editing core = src/owned/edit.rs (moves, unlink/replace, set/remove_attribute, declare_namespace, set_name, set_url, compact). Invariant: attached tree namespace-consistent (each element/attr prefix resolves to its stored URI). `reconcile(root, context)` = read-only `plan` (declare (prefix,uri) on topmost element needing it, never rename; 2nd pass = same-element conflict -> `Namespace`) + quotas + reserve + commit. Structural ops plan with `context` = new parent before relinking; attribute/name ops apply, reconcile, undo (`pop_attribute`/`restore_attribute`/old name) on failure. Detached subtree = live records, root parent NONE, outside `nodes()`. Attr ranges contiguous: growing a non-tail range relocates it to the tail (garbage); never truncate the arena outside `compact` (empty ranges may point past the tail; exception: copy rollback truncates back to the pre-call length, which every older range fits). Entity-ref content is structurally read-only (`ProtectedNode`). `append_*` never merge Text; only `append_child` (xmlAddChild); 2.15 sibling inserts don't merge.
- Copies = src/owned/copy.rs: `Editor::import(&OwnedDocument<B>, id, deep)` (xmlDocCopyNode), `Editor::copy` (xmlCopyNode, shares pool ranges: pool is append-only, nothing mutates bytes), `OwnedDocument::try_clone` (xmlCopyDoc, faithful incl. tombstones/counters). Pure `stage` (source preorder -> scratch records numbered from dest `nodes.len()`; root attrs staged last so root declarations grow the attr tail in place) then `publish` (reserve all, push unreachable, `reconcile_copy`, truncate back on failure). `reconcile_copy` = per-element `plan`, then `hoisted` seed (one decl per prefix on the root, = xmlDocCopyNode) re-planned; kept when Ok and not longer. Destination decides: undeclared EntityRef -> its content inlined (root -> `Hierarchy`), kept attr forms dropped, `is_id`, HTML<->XML (`xml_problem` / `Namespace`). `remove` clears `slots_are_preorder` itself (a detached copy root has no parent to detach). No adopt by design (docs/bindings.md). Oracle copy ops skip 3 documented divergences (`diverges` in tests/dom_edit_oracle.rs).
- DOM accessors (both DOMs) are generic fns in src/xpath/tree.rs over `Navigate`: `scope` (stops below EntityRef = libxml2 entity-decl parent), `base`/`resolve_base` (TextReader, XInclude, catalog), `lang`, `space_preserve` (NOBLANKS), `path` (Schematron), `search_ns*`, `ns_list`, `property` (+ `Dtd::default_value`). Differential: tests/dom_edit_oracle.rs + tooling/libxml2_domedit.c (`YAXML_DOMEDIT_HELPER`, `_CASES`, `_SEED`); fuzz target `domedit` (fuzz/domedit.rs, `YAXML_DOMEDIT_TRACE=1` prints ops).
- Invariants are structural, not re-checked (fuzz-coverage pass 2026-10-19): `StreamingSession` keeps no delivery state (callers lend then acknowledge before preparing again; `drive` does both); replacement text is tokenized as UTF-8 whose source offsets are its decoded offsets (one span type, no local flag; its characters were checked at declaration/load); `SourceOrigin::close_element`/`join_text` are infallible; DOM builders trust the parser's balanced ends. A cut-off start tag/CDATA at EOF fails `check_token_start` in every reader (`Tokenizer::cut_kind`). Don't re-add defensive `InvalidState` arms: delete states the types/control flow exclude; keep only allocation/limit guards reachable by input.
- DTD declaration model: `valid::Dtd` owns all declaration storage (catalog writes `self.dtd.*`): DOM builders move it out of the finished catalog (`Reader::take_dtd`/`StreamingSession::take_dtd`; a clone cost +10% on DTD-heavy parses); `entities: Vec<EntityDecl>` (decl order, dup dropped; `external_subset` = catalog `reading_external_subset`, set by `include_subset`/`external_dtd`), `general` (bound; standalone docs' external general entities stored but unbound), `parameter`, `declared` (first general of any kind, ENTITY validation); `notations` Vec+`notation_index`; `ElementDecl.model` = printed model (`save::dtd::content_model`, charged to storage). Public borrowed views `valid::{Entity, Element, Attribute, Notation}` + `Dtd::{entity, parameter_entity, entities, element, elements, attribute, notation, notations}`, `valid::predefined_entity`; `AttributeKind` defined in valid (dtd re-exports). Unparsed entity `content` = notation (libxml2). `save::encode_entities(Escape)`/`encode_special_chars`/`escape_text` and `TextWriter` share `save::escape_into` (String, tables CONTENT/QUOT/HTML/ATTRIBUTE); `Out::text` is the encoded-output escaper. `yaxml::chars` = chvalid (4th-ed tables in regexp/unicode.rs via gen_unicode.py). External PE inside an entity value loads only with NOENT|DTDVALID (`xmlExpandPEsInEntityValue`). Differential: tests/dtd_oracle.rs + tooling/libxml2_dtd.c (`YAXML_DTD_HELPER`); fuzz checks in fuzz/dtd.rs.
- Diagnostics: `Error` stays `{ kind, offset }` (nothing added on any hot path). src/diagnostic.rs = public `Diagnostic` (xmlError shape), `code` consts, `LineIndex` (libxml2 line/col, UTF-16/single-byte transcoded, offsets stay input bytes), `render` (xmlFormatError + xmlParserInputGetWindow), validators' `describe`, `Node/OwnedNode::line` (impl kept there, not in src/owned*). src/diagnostic/reread.rs = `Scan` of the markup skeleton to the offset, then the construct re-read through ports of parser.c error paths (tags, comment/PI/CDATA, XML decl, DTD decls, entity replacement text: errors inside entities reported after the reference, nested ones as `entity`). Re-reader budget `Work` (8/byte + 64 KiB, shared per describe_all; exhausted -> fallback code, column 0): charge any new scan or expansion, never swallow `EXHAUSTED` via `.ok()`. Navigate has `range` (`offset` defaults from it). Oracle helper tooling/libxml2_errors.c (`YAXML_ERRORS_HELPER`) -> tests/diagnostic_oracle.rs; yaxmllint stderr -> `parse_errors_against_xmllint`. TextReader line/column = parsing point (`source.position()`): a per-node offset cost 0.3-0.7% instructions.
- Budgets (docs/security.md#work-and-memory-budgets): nodes <= `max_events` (~200 B/node); `max_total_attributes` (4 M) is charged where DOM builders store attributes (`Budget::charge_attributes` in dom.rs Start/Empty arm and `owned::store_content`), never in the parser/stream hot path, so streaming readers ignore it. DTD-driven validation lookups are hashed (`Validator.mixed/enumerated`, `required` map); keep any new per-child/per-attribute DTD scan O(1). `examples/adversarial_scaling.rs` (modes dom/owned/reader/push/buffered/text/html, env FLAGS/DEFAULTS/CHUNK/MIXK) is the scaling series; `tests/budgets.rs` pins the fixes.
- No I/O without a `Resolver` (src/resolve.rs); `FileResolver` is root-confined. Entity amplification follows libxml2 (`max_entity_amplification`, default 5).
- Catalogs (docs/catalog.md): XML `Entry` = `value` (target as written: what `dump`/`remove` use) + `url` (resolved: what lookups use); `Kind::Group{id,prefer}` entries stay in file order (members' `group` = id); `Kind::Inert` = removed or failed to load (never matches, not dumped); `Kind::Catalog` = add-only type. `dump` escapes with `save::escape_into(ATTRIBUTE, hex)`; SGML = `Named` map of every keyword, dump sorted by key. `CATALOG_PI`: `ParserState::note_catalog` (both PI sites) -> `take_catalogs`, drained at the DOCTYPE handoff (`Reader::start_dtd`, `StreamingSession::start_dtd`) and after each content publish (`content.rs`) -> `Loader::catalog_pi` -> `Resolver::catalog_pi` (default no-op; `resolve::share` forwards it). `CatalogResolver` keeps them in `Catalog.local` (a `NextCatalog` list; `resolve_all` = `xmlResolveFromCatalog` order), bounded by `Limits::max_local`. Differentials (`YAXML_CATALOG_HELPER`, `YAXML_CATALOG_SEED`): tests/catalog_oracle.rs (lookups, `edits_and_dumps_match_libxml2`), tests/catalog_pi.rs; libxml2's global catalog file cache outlives a parse in one process, so helper `cd`/`load` clear it. Not matched: libxml2 stops dumping a group whose first member failed to load.
- `RECOVER` (DOMs only): error sites call `Budget::recover` (src/parser.rs; strict -> Err, recover -> record + libxml2 repair at that site). Unrepaired error ends the parse: DOM builders call `Budget::conclude` and close open elements. Limits/loops/alloc stay fatal; no element -> rootless doc (`document_element()` None; empty input -> Err). DTD errors: `DtdControllerCore::recover` cuts the subset (salvaging libxml2's partial ENTITY/ATTLIST) and content resumes per `reader::recovered_doctype` (streams replay decoded bytes). Slice reader only (`ParserState::rereading`): rereads a malformed tag's rest (`take_rewind`), repairs non-Char chars, keeps undeclared entity refs; OwnedDocument repairs invalid UTF-8 (`encoding::repair_utf8`). Fuzz asserts recovery is a fixed point and nodes <= bytes without `&`. Divergences: docs/compatibility.md#recovery-recover. Oracle: `recover_against_xmllint` (YAXML_XMLLINT, YAXML_SUITES).
- Output: `save::to_writer` is the one serializer (`to_vec` = into a Vec); `Out` spills at `CHUNK` only via `checkpoint()` between nodes (a per-`raw` check cost 2-6% instr); `Out::sibling` (DTD notation buffering) has no sink. HTML serializer `html::serialize::dump(node, ..)` streams the same way and dumps any owned node (subtrees). `TextWriter` (src/textwriter.rs) = `Machine` (pure libxml2 xmlwriter.c state machine writing one call into `out: String`) + I/O/limits/encoding in `call`/`commit`; NOT layered on `Writer` (contracts conflict). Differential: tests/text_writer_oracle.rs + tooling/libxml2_textwriter.c (`YAXML_TEXTWRITER_HELPER`, `_CASES`, `_SEED`); scripts in fuzz/text_script.rs (shared with fuzz `writer`). Only divergence class: stale ns entries matched by libxml2 via reused malloc addresses.
- Capabilities/reset: src/features.rs (`Feature` = `XML_WITH_*` numbers, `has`/`has_code`/`all`, `VERSION`, `LIBXML2_COMPAT_VERSION(_NUMBER)`, `check_version`). `reset`/`reset_with` on PushParser/BufferedReader/TextReader = `StreamingSession::reset` -> `Stream::recycled` -> `ParserState::recycled`/`Tokenizer::recycled`: build a fresh value and move over only emptied Vec/HashMap/String capacity (never copy a scalar; add new ParserState fields to `new` only and they reset for free). Resolver always dropped; `reset()` keeps flags+limits. Measured -13..17% on 100k tiny docs (examples/reset_bench.rs). Not done: DOM builders/Reader reset.

## Repo/process
- API inventory: `docs/libxml2-api.tsv` columns `status`,`rust` come from `tooling/api_status.py` (TABLE override block + name rules; `uv run --no-project tooling/api_status.py` regenerates, needs `YAXML_LIBXML2_SOURCE`=libxml2-2.15.4 tree for error code numbers; `--check` verifies without it). Adding/removing public API: edit TABLE, regenerate, commit the TSV. `tests/api_inventory.rs` fails when an implemented/partial path is missing from src/. Rust paths use `mod::Type::member`; notes follow ` - `.
- Canonical repo: bare `../yaxml.git`; worktrees `../yaxml-wt/<name>`, main in `../yaxml-wt/main`. Visible workspace dir has no `.git`.
- Process: docs/process.md (one slice, one review; measured claims). Legacy evidence docs: docs/archive (not maintained).
- Oracle: `../yaxml-oracle/build/xmllint`, `libxml2.a`, source `../yaxml-oracle/libxml2-2.15.4`. URI helper build: docs/uri.md. XMLTS: `../yaxml-suites/xmlconf` + `xmlconf-catalog.tsv`.
- Python: run with `uv run --no-project` (hook rejects python3).

## Fuzz
- Targets `fuzz/fuzz_targets/*.rs` are thin wrappers over `fuzz/driver.rs` `exercise_*`. Corpus `fuzz/corpus/<t>` (files <= 4 KiB, edge-only cmin), `fuzz/regressions/<t>` replayed by tests/fuzz_smoke.rs, unfixed findings in `fuzz/open/`.
- Coverage: `fuzz/coverage.sh` -> per-target lcov unioned by `coverage_merge.py` (multi-object llvm-cov undercounts). Campaign flags: `-fork=1 -timeout=2`.

## Conventions
- Deliberate libxml2 divergences are listed in the module doc (e.g. docs/xsd.md "Differences"). libxml2 quirks are matched unless they are bugs that break spec validity or security.
- Table-driven tests, happy + sad paths. Update docs/compatibility.md rows with each feature.
