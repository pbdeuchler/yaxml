# yaxml agent notes

Pure-Rust libxml2 2.15.4 rewrite. `#![forbid(unsafe_code)]`; memchr is the only library dep. Benchmarks, fuzzing, libxml2 differentials and the XMLTS run live in the sibling repo yaxml-harness (see Harness); paths written `yaxml-harness/...` are there. Package = src + README (doctested via cfg(doctest)) + LICENSE-*; src must not include_str! anything outside src; keep `include` in Cargo.toml in sync. FFI bindings live in `bindings/` (own Cargo workspace + lockfile; not in the package; approved, docs/bindings.md).

## Layout
- One engine (src/parser.rs, src/tokenizer, src/stream) feeds Reader (slice), PushParser, BufferedReader, TextReader, Document (borrowed DOM), OwnedDocument (arena, `OwnedNodeId`). DTD-free input stays on the plain token loop; DTD stack = src/dtd*.
- `ParseOptions` (src/options.rs) is the single entry for flags (libxml2 `XML_PARSE_*` values), `Limits`, `DecodeLimits`, `base`, `Resolver`. Default = libxml2 default (entity-ref nodes kept, nothing loaded). Unimplemented flags -> `ErrorKind::UnsupportedOption`, never silently ignored.
- Config structs (every `Limits`/`Options`/`ParseOptions`/`EditLimits`/`WriterLimits`/`DecodeLimits`) are `#[non_exhaustive]` with pub fields, `Default` = `const DEFAULT`; outside the crate build via `X::DEFAULT.field(v)` chains (setters from `setters!` in src/setters.rs; list every field there, a missing one fails to compile) or field assignment; no struct literals. tests/defaults.rs pins every default: update it with any default change (docs/bindings.md#configuration-structs).
- Crate-private `Navigate` (src/xpath/tree.rs) is shared by XPath, C14N, valid, relaxng, xsd, pattern, schematron.
- Feature `allocator_api` (Rust 1.100): `OwnedDocument<A = Global>`/`OwnedNode<'d, A>`/`Editor<'d, A>`; nodes+attributes in `allocator::Vec<_, A>` (one clone of `A` each), `parse_in`/`create_in`/`allocator()`. src/allocator.rs is the only cfg switch (off = sealed stand-in, MSRV 1.97, API unchanged). Pool/ids/dtd/errors/scratch stay global. Generic consumers: `Navigate` users + Writer (`save::Walk`); `save::Tree`/`to_vec`/html/xinclude Global-only (generic public `Tree` breaks `Tree::Borrowed(..)` inference). `parse_in` rejects XINCLUDE. Keep new constructors in `impl OwnedDocument` (Global) so `OwnedDocument::parse(..)` infers. Derive Copy/Clone on A-generic views manually (derive adds `A: Copy`).
- relaxng: one `Engine<I>` (src/relaxng.rs: start/flush/text/end/finish) driven by the DOM walk and by `relaxng::Stream` (events; used by `TextReader::relaxng_set_schema`). `Deriver` holds `Arc<Arena>`/`Arc<Tables>` so `Stream` has no lifetime. No subtree buffering (libxml2 FullElement unneeded).
- XSD instance validation is one event engine (src/xsd/validate.rs `Validator`: start/text/end/other); tree `run` and public `xsd::StreamValidator` both feed it. Stream == DOM diagnostics is tested (tests/xsd_stream.rs, suite, tests/support/fuzz/xsd.rs). `Schema` = `Arc<Compiled>` (crate-private, fields via `schema.data`), so `StreamValidator`, `Validator`, `Engine` and `pattern::StreamMatcher` (`Arc<Stream>`, state split in `Cursor` so no per-event clone) have no lifetime. `TextReader.validators` (dtd + relaxng + xsd) is the one feeding point (`fetch`, `skip_entity`, Doctype -> `set_dtd`, `sync` after every fetched event); `xsd_set_schema`/`xsd_diagnostics`; `is_valid` = any set and none failing.
- DTD validation is one event engine (src/valid/engine.rs `Validator`: start/text/other/flush/end; Glushkov `Model` state per open element, ID set, IDREFs checked when the root ends). Tree `engine::run` walks the tree (EntityRef = `other`: content of EMPTY; Text = flush+text so tree text nodes stay runs) and stable-sorts by a `(element ordinal, phase)` key into xmlValidateDocument preorder, rewording ContentModel; stream (src/valid/stream.rs `StreamValidator`, public) keeps push wording (`Misplaced x`/`Text not allowed`/`Expecting more children`, once per element) and document order. Root start tag is held (`Root`) until `set_dtd`/next event: the stream loads the external subset while reading it, so the DTD is complete only after that event. `set_dtd` copies until the root is checked, then only reports new `dtd.issues` (parser-time NotStandalone etc.). Empty DTD/no DTD in stream = SAX `Validation failed: no DTD found !` (tree validates against an empty DTD: the one stream/tree difference). TextReader `DTDVALID`: source built without it, then `set_flags` with it (loads like libxml2). Stream == tree: tests/valid_stream.rs (+ `--ignored` suites and xmllint differentials), tests/support/fuzz/valid.rs.
- TextReader: `NOBLANKS` is decided at fetch with src/blanks.rs `Blanks` (areBlanks incl. the `*space=-2` rule that the DOM `xpath::tree::blanks` shares; declared content from its DTD at open; `Node.replaced` marks NOENT replacement text, never dropped), so buffered subtrees match the tree; the source never sees the flag (`streaming`). `PushParser`/`BufferedReader` apply the same core as `blanks::Filter` (holds a blank run until the next event; entity content passes; declared content via `Budget::content`, which `content::note_content` sets for every DTD-stack start tag under NOBLANKS); `Reader` rejects NOBLANKS. `set_parser_property` = `BufferedReader::set_flags` on a pristine session (resolver kept). Attribute value children (`read_attribute_value`) are `Node.parts`, split from `Budget::kept` taken right after a Start/Empty event (`Attr.position`); no kept form = one text, even empty. libxml2 quirks matched: `IsDefault` false, `Normalization` true, `Standalone` -1/-2/0/1, NodeType 6/9/11/12/13/16/17 never emitted (verified with xmllint --stream --debug; 13 because `xmlNodeGetSpacePreserve(text)` is -1). Rejected, with reasons in docs/textreader.md: CurrentNode/CurrentDoc/Preserve/PreservePattern. Errors are returned (no handlers); `line_number`/`column_number` = parsing point via `source.position()` in a caller `LineIndex`. Differential: yaxml-harness/tooling/libxml2_textreader.c takes FLAGS; `noblanks_streams_match_xmllint` needs YAXML_XMLLINT.
- Streaming hot path: tokenizer `step` (src/tokenizer.rs) is one memchr step per lexical state (no per-byte calls; a markup prefix classifies all its available bytes in one step); `Stream::advance`/`Tokenizer::advance` are `inline(always)`, token runs append within spare capacity without the checked growth path; plain UTF-8 bypasses the decoder (`Stream::advance`). Stream `ParserState` is `lending_namespaces`: names get placeholder `LENT`, `ParserState::lend` fills them from bindings at delivery, closed scopes unwind at the next `process_token` (`settle`); DTD handover calls `stop_lending`. Perf method/table: docs/benchmarks.md (matched driver + `/usr/bin/time -l` instruction counts under host load). PushParser holds only the session (failure/finish/`max_input_bytes` live in `StreamingSession`) and the NOBLANKS filter (strict `feed` keeps its plain closure; `feed_filtered` is out of line). Callbacks are `FnMut(&Event, SourceOrigin)`: `deliver` lends the event by reference (attribute list stays `Attributes::Owned`, capacity recycled via `parser::emptied`); while lending, normalized values go to `ParserState::lent` (boxed on first use: state size taxes every slice-reader construction, 496 B cost tiny reader 9%) with `LENT_VALUE` ("\0") placeholders filled in `lend`/`lend_event` (inline(always)); namespace-declaration values are never lent; `settle` clears. Slice reader: `read_step` dispatches once on `rereads()` to `step::<REREADS>` -> `read_token::<REREADS>` (`process_token` = `read_token::<false>` for every other frontend), so strict parsing compiles without recovery checks; `normalized` is inline (no-change scan), `normalize` out of line; `delimited_body` inline(always) (constant delimiters, no memcmp); `invalid_char` <16 bytes uses a table. Measured dead ends (don't retry): in-place `drive_chunk` below 32 bytes (+6% instr, tails rarely hold a token), scalar loops instead of memchr on short haystacks (+2%), `inline(always)` on `process_token` (-2% instr but +6-11% cycles); cold/`inline(never)` helpers or tail calls for recovery checks without the const generic (LLVM re-spills elsewhere, no gain); `invalid_char` table scan beyond 16 bytes (2.3x worse at 40); SWAR control screen. Never write `Self { a, b: a && c, ..self }` builders: rustc 1.95/1.96 SimplifyComparisonIntegral miscompile (fixed in 1.97, the MSRV; rust-toolchain.toml pins 1.97.0) (rust-lang/rust#158206) drops `a`; check with tooling/simplify_comparison_scan.py. Exact per-feed instruction traces: lldb single-step script in docs/benchmarks.md method. rustc 1.97 emits v0 symbols (`_RNv...`): set lldb breakpoints by `nm` address, not legacy `_ZN` names. Sixth series (docs/benchmarks.md): 63/65, losses mixed/namespaces push/7. DTD family rows (`dtd-decl/refs/nested/attrs`, `dtd`; helper profile `dtd` = NOENT): see next bullet.
- DTD content path (src/dtd_controller/content.rs, src/dtd_tag.rs): stable input (slice reader, DOMs) and entity replacement text are scanned in place by `content::scan` (no token copies; the `Work` ledger charges scanning); push reads plain UTF-8 chunks in place (`drive_chunk`). Buffered can't lend from `fill_buf` (breaks `position()` == consumed source, tests/buffered.rs) and gained <2% when tried: its gap is per-event session layering (lend/prepare/drive). Replacement tokens go through the physical path (`publish_replacement`, `ParserState.replacement`: markup errors stop instead of recovering). Each entity's text is scanned once into cached `Piece`s (memory charged as catalog storage); every reference still charges its whole expansion to the amplification/expansion ledgers (tests/amplification.rs). `Recent<T>` = 64-slot direct-mapped caches in front of the SipHash maps for entity/element lookups: unkeyed slot index, collisions only evict, so worst case = the keyed lookup; keep SipHash behind it. One start-tag path `start_element::<_, DTD>` + `TagDeclarations` (one declaration lookup per tag, unchanged values borrowed via `DtdCatalog::unchanged`, defaults appended: charge = `ElementDecl.copied` total less specified attrs, declarations walked only to copy (DTDATTR/`namespace_defaults`) or note standalone); linear duplicate/attribute scans only below small thresholds (hash past them; keep bounded, cf. adversarial_scaling). PI catalogs in content: `note_catalogs` in both publishers. Results/remaining gaps: docs/benchmarks.md "DTD-heavy parsing".
- Attribute entity refs without NOENT (libxml2 attr children): `dtd_tag::kept_form` -> `TagDeclarations::value` -> `Budget::kept()` (last start tag, by final attribute position; DOM builders drain it) -> sorted side tables `Document.kept` / `OwnedDocument.kept` (allocator Vec, pool ranges); empty = zero cost. Public `unexpanded_attribute(pos)`; `save` (`Walk::kept_form`) and yaxmllint `--xpath` write it; `attributes()` values stay substituted (XPath/valid/C14N). ATTLIST defaults carry `StoredDefault::Value.kept` (DTDATTR). Writer writes substituted. Owned `set_attribute_value` drops the form.
- Owned editing core = src/owned/edit.rs (moves, unlink/replace, set/remove_attribute, declare_namespace, set_name, set_url, compact). Invariant: attached tree namespace-consistent (each element/attr prefix resolves to its stored URI). `reconcile(root, context)` = read-only `plan` (declare (prefix,uri) on topmost element needing it, never rename; 2nd pass = same-element conflict -> `Namespace`) + quotas + reserve + commit. Structural ops plan with `context` = new parent before relinking; attribute/name ops apply, reconcile, undo (`pop_attribute`/`restore_attribute`/old name) on failure. Detached subtree = live records, root parent NONE, outside `nodes()`. Attr ranges contiguous: growing a non-tail range relocates it to the tail (garbage); never truncate the arena outside `compact` (empty ranges may point past the tail; exception: copy rollback truncates back to the pre-call length, which every older range fits). Entity-ref content is structurally read-only (`ProtectedNode`). `append_*` never merge Text; only `append_child` (xmlAddChild); 2.15 sibling inserts don't merge.
- In-context parsing = `Editor::parse_content` (src/owned/copy.rs; xmlParseInNodeContext/xmlCtxtParseContent, balanced chunk = on `root()`). Detached result by design (names need context bindings; HTML `parse_fragment` returns a doc instead). Path: `OwnedDocument::parse_tree(.., Some(Context))` -> `Reader::in_context` (cursor 0, `ParserState::in_context`: `fragment` = Content phase never Epilog, `initial=usize::MAX` so `<?xml` is a misnamed PI, bindings seeded via `bind`); doc with DTD -> `DtdController::seeded` (catalog `seed`: entities with `input` cleared + notations, no ATTLIST: libxml2 fresh ctxt has no attsDefault) -> scratch doc (root children = content; `blanks(tree, content)` treats root as `#root`, trailing blank kept) -> `stage` into one `Staged` per top-level node + `publish(.., reconcile closure)` planning with `Some(context)`; `Target.same=true` (refs resolve). Errors `EditErrorKind::Parse(kind)`+`value_offset`; `LineIndex::content` (`Scan.content`: top-level `</`=85, no prolog/epilog, `<!DOCTYPE`=start tag). Differential yaxml-harness/tests/fragment_oracle.rs + tooling/libxml2_fragment.c (`YAXML_FRAGMENT_HELPER`, `_CASES`, `_SEED`; mode W = whole-document control: divergences a whole doc shows too are counted, not failed); fuzz target `fragment` (tests/support/fuzz/fragment.rs, reuses `domedit::check`/`snapshot`).
- Copies = src/owned/copy.rs: `Editor::import(&OwnedDocument<B>, id, deep)` (xmlDocCopyNode), `Editor::copy` (xmlCopyNode, shares pool ranges: pool is append-only, nothing mutates bytes), `OwnedDocument::try_clone` (xmlCopyDoc, faithful incl. tombstones/counters). Pure `stage` (source preorder -> scratch records numbered from dest `nodes.len()`; root attrs staged last so root declarations grow the attr tail in place) then `publish` (reserve all, push unreachable, `reconcile_copy`, truncate back on failure). `reconcile_copy` = per-element `plan`, then `hoisted` seed (one decl per prefix on the root, = xmlDocCopyNode) re-planned; kept when Ok and not longer. Destination decides: undeclared EntityRef -> its content inlined (root -> `Hierarchy`), kept attr forms dropped, `is_id`, HTML<->XML (`xml_problem` / `Namespace`). `remove` clears `slots_are_preorder` itself (a detached copy root has no parent to detach). No adopt by design (docs/bindings.md). Oracle copy ops skip 3 documented divergences (`diverges` in yaxml-harness/tests/dom_edit_oracle.rs).
- DOM accessors (both DOMs) are generic fns in src/xpath/tree.rs over `Navigate`: `scope` (stops below EntityRef = libxml2 entity-decl parent), `base`/`resolve_base` (TextReader, XInclude, catalog), `lang`, `space_preserve` (NOBLANKS), `path` (Schematron), `search_ns*`, `ns_list`, `property` (+ `Dtd::default_value`). Differential: yaxml-harness/tests/dom_edit_oracle.rs + yaxml-harness/tooling/libxml2_domedit.c (`YAXML_DOMEDIT_HELPER`, `_CASES`, `_SEED`); fuzz target `domedit` (tests/support/fuzz/domedit.rs, `YAXML_DOMEDIT_TRACE=1` prints ops).
- Invariants are structural, not re-checked (fuzz-coverage pass 2026-10-19): `StreamingSession` keeps no delivery state (callers lend then acknowledge before preparing again; `drive` does both); replacement text is tokenized as UTF-8 whose source offsets are its decoded offsets (one span type, no local flag; its characters were checked at declaration/load); `SourceOrigin::close_element`/`join_text` are infallible; DOM builders trust the parser's balanced ends. A cut-off start tag/CDATA at EOF fails `check_token_start` in every reader (`Tokenizer::cut_kind`). Don't re-add defensive `InvalidState` arms: delete states the types/control flow exclude; keep only allocation/limit guards reachable by input.
- DTD declaration model: `valid::Dtd` owns all declaration storage (catalog writes `self.dtd.*`): DOM builders move it out of the finished catalog (`Reader::take_dtd`/`StreamingSession::take_dtd`; a clone cost +10% on DTD-heavy parses); `entities: Vec<EntityDecl>` (decl order, dup dropped; `external_subset` = catalog `reading_external_subset`, set by `include_subset`/`external_dtd`), `general` (bound; standalone docs' external general entities stored but unbound), `parameter`, `declared` (first general of any kind, ENTITY validation); `notations` Vec+`notation_index`; `ElementDecl.model` = printed model (`save::dtd::content_model`, charged to storage). Public borrowed views `valid::{Entity, Element, Attribute, Notation}` + `Dtd::{entity, parameter_entity, entities, element, elements, attribute, notation, notations}`, `valid::predefined_entity`; `AttributeKind` defined in valid (dtd re-exports). Unparsed entity `content` = notation (libxml2). `save::encode_entities(Escape)`/`encode_special_chars`/`escape_text` and `TextWriter` share `save::escape_into` (String, tables CONTENT/QUOT/HTML/ATTRIBUTE); `Out::text` is the encoded-output escaper. `yaxml::chars` = chvalid (4th-ed tables in regexp/unicode.rs via gen_unicode.py). External PE inside an entity value loads only with NOENT|DTDVALID (`xmlExpandPEsInEntityValue`). Differential: yaxml-harness/tests/dtd_oracle.rs + yaxml-harness/tooling/libxml2_dtd.c (`YAXML_DTD_HELPER`); fuzz checks in tests/support/fuzz/dtd.rs.
- Diagnostics: `Error` stays `{ kind, offset }` (nothing added on any hot path). src/diagnostic.rs = public `Diagnostic` (xmlError shape), `code` consts, `LineIndex` (libxml2 line/col, UTF-16/single-byte transcoded, offsets stay input bytes), `render` (xmlFormatError + xmlParserInputGetWindow), validators' `describe`, `Node/OwnedNode::line` (impl kept there, not in src/owned*). src/diagnostic/reread.rs = `Scan` of the markup skeleton to the offset, then the construct re-read through ports of parser.c error paths (tags, comment/PI/CDATA, XML decl, DTD decls, entity replacement text: errors inside entities reported after the reference, nested ones as `entity`). Re-reader budget `Work` (8/byte + 64 KiB, shared per describe_all; exhausted -> fallback code, column 0): charge any new scan or expansion, never swallow `EXHAUSTED` via `.ok()`. Navigate has `range` (`offset` defaults from it). Oracle helper yaxml-harness/tooling/libxml2_errors.c (`YAXML_ERRORS_HELPER`) -> yaxml-harness/tests/diagnostic_oracle.rs; yaxmllint stderr -> `parse_errors_against_xmllint`. TextReader line/column = parsing point (`source.position()`): a per-node offset cost 0.3-0.7% instructions.
- Budgets (docs/security.md#work-and-memory-budgets): nodes <= `max_events` (~200 B/node); `max_total_attributes` (4 M) is charged where DOM builders store attributes (`Budget::charge_attributes` in dom.rs Start/Empty arm and `owned::store_content`), never in the parser/stream hot path, so streaming readers ignore it. DTD-driven validation lookups are hashed (`Validator.mixed/enumerated`, `required` map); keep any new per-child/per-attribute DTD scan O(1). `yaxml-harness/examples/adversarial_scaling.rs` (modes dom/owned/reader/push/buffered/text/html, env FLAGS/DEFAULTS/CHUNK/MIXK) is the scaling series; `tests/budgets.rs` pins the fixes.
- No I/O without a `Resolver` (src/resolve.rs); `FileResolver` is root-confined. Entity amplification follows libxml2 (`max_entity_amplification`, default 5).
- Catalogs (docs/catalog.md): XML `Entry` = `value` (target as written: what `dump`/`remove` use) + `url` (resolved: what lookups use); `Kind::Group{id,prefer}` entries stay in file order (members' `group` = id); `Kind::Inert` = removed or failed to load (never matches, not dumped); `Kind::Catalog` = add-only type. `dump` escapes with `save::escape_into(ATTRIBUTE, hex)`; SGML = `Named` map of every keyword, dump sorted by key. `CATALOG_PI`: `ParserState::note_catalog` (both PI sites) -> `take_catalogs`, drained at the DOCTYPE handoff (`Reader::start_dtd`, `StreamingSession::start_dtd`) and after each content publish (`content.rs`) -> `Loader::catalog_pi` -> `Resolver::catalog_pi` (default no-op; `resolve::share` forwards it). `CatalogResolver` keeps them in `Catalog.local` (a `NextCatalog` list; `resolve_all` = `xmlResolveFromCatalog` order), bounded by `Limits::max_local`. Differentials (`YAXML_CATALOG_HELPER`, `YAXML_CATALOG_SEED`): yaxml-harness/tests/catalog_oracle.rs (lookups, `edits_and_dumps_match_libxml2`, `catalog_pi_matches_libxml2`; behaviour in tests/catalog_pi.rs); libxml2's global catalog file cache outlives a parse in one process, so helper `cd`/`load` clear it. Not matched: libxml2 stops dumping a group whose first member failed to load.
- `RECOVER` (every surface: DOMs, `Reader`, `PushParser`, `BufferedReader`, `TextReader`): error sites call `Budget::recover` (src/parser.rs; strict -> Err but Namespace (recorded, see Namespace errors bullet), recover -> record + libxml2 repair at that site). Unrepaired error = stop: the reader records it (`Reader::stop`/`End::Stopped`, `StreamingSession::stop`; past a cut -> the cut, `Stream::terminal`) and closes what is open with End/EntityEnd events at the error offset (`ParserState::close_open`, `ContentControllerCore::close_open` walks entity frames); DOM builders only consume events (`Budget::conclude` takes the list; no closing loops). Stopped push ignores input (`stopped`, checked only under `finalizing`). Limits/loops/alloc/resolver stay fatal; no element -> rootless doc (`document_element()` None; empty input -> Err). DTD errors: `DtdControllerCore::recover` cuts the subset (salvaging libxml2's partial ENTITY/ATTLIST) and content resumes per `reader::recovered_doctype` (streams replay decoded bytes). DTD-free token loops reread (`ParserState::rereads`, `read_token::<true>`; undeclared refs split in its text arm, `take_reference_end` -> EntityEnd): the slice reader moves its cursor; `Stream` keeps a boxed `Recovery` (replay buffer filled at parse, applied at `release_in`, stepped back when the token came from it; `screen` cuts at invalid UTF-8 and turns on `repair_characters`; `Tokenizer::finish_cut_start`). The DTD stack neither rereads nor repairs (documented divergence). Strict paths pay nothing: `advance_in`/`finish_in`/`release_in::<REREADS>`, `drive_recovering`, `lend_recovering`, `BufferedReader::read_lent::<RECOVERS>`; keep recovery helpers `#[cold] #[inline(never)]` (inlining them into `Reader::read_event`/`StreamingSession::drive` cost 1-7% strict instructions; check with parse_bench + `/usr/bin/time -l`). `BufferedReader` under RECOVER/NOBLANKS reads through `Detached` copies (`detach`; Declaration/Doctype as `Declared`): a lend error can't be handled while the lent event is returned (NLL problem case 3). Recovered errors of decoded/replacement tokens are remapped to source/reference offsets (`Budget::remap`). OwnedDocument repairs invalid UTF-8 (`encoding::repair_utf8`); `Document` and streams cut. Fuzz: tests/support/fuzz/recover.rs (push/pull/slice equal for any chunking, DOM projection) + DOM fixed point. Divergences: docs/compatibility.md#recovery-recover. Oracles: `recover_against_xmllint` (save output), `streams_recover_against_xmllint` (walker dump; YAXML_XMLLINT, YAXML_SUITES).
- Output: `save::to_writer` is the one serializer (`to_vec` = into a Vec); `Out` spills at `CHUNK` only via `checkpoint()` between nodes (a per-`raw` check cost 2-6% instr); `Out::sibling` (DTD notation buffering) has no sink. HTML serializer `html::serialize::dump(node, ..)` streams the same way and dumps any owned node (subtrees). `TextWriter` (src/textwriter.rs) = `Machine` (pure libxml2 xmlwriter.c state machine writing one call into `out: String`) + I/O/limits/encoding in `call`/`commit`; NOT layered on `Writer` (contracts conflict). Differential: yaxml-harness/tests/text_writer_oracle.rs + yaxml-harness/tooling/libxml2_textwriter.c (`YAXML_TEXTWRITER_HELPER`, `_CASES`, `_SEED`); scripts in tests/support/fuzz/text_script.rs (shared with fuzz `writer`). Only divergence class: stale ns entries matched by libxml2 via reused malloc addresses.
- HTML (src/html*, docs/html.md): one `Engine<S: Sink>` (decode/sniff/meta switch, `Tokenizer`, `Tree<S>`) drives pull, push (`Push<S>`), events and fragments. `Tree` = HTMLparser.c tree logic emitting SAX calls; `stack: Vec<(name, S::Node)>` is also the SAX2 node stack (HTML5: separate `nodes`, name stack holds last start tag only); `prioritized` arrays replace hashing for the 11 end-priority names (was -10..20% instr). Sinks: `Document` (xmlSAX2 builder, `Node = NodeId`: depth ceiling = nodePush, text merge ceiling, DOCTYPE kept only `first`, areBlanks tail `blanks`) and `Events` (`Node = ()`, closure gets `html::Event`, `Break` = xmlStopParser; no depth ceiling; NOBLANKS drops ignorable text silently = libxml2's no-op ignorableWhitespace). Fragment = `#root` (sink `root()`) on the stack, no implied, tokenizer `fragment()`, encoding param = context `html_encoding`. Discarded start tag with empty stack -> `Reaction::Reread`. Lines are lazy (zero parse cost, keep it so; hot loop is instruction-sensitive: no per-token counting, cold `irregular()` for invalid input): node origin = empty range at the decoded-text offset whose line libxml2 records (element `>`, comment end, text run start in `Tree.run`); `HtmlMeta.decoding` (`html::Decoding`: BOM skip, first decoder, <=1 switch from passthrough) lets `LineIndex::html`/`Summary::line_index` rebuild the text; `Navigate::marks_lines` -> `node_line` uses `text_line(range.start)`. Diagnostic = offset + `mark` (line offset) + `early` (raised before a re-decoding switch: window from raw text, `LineIndex.raw`); describe/render take the index; column = chars (NOT libxml2's int2); converter errors at the token holding the first malformed char; cap 100. Oracle: yaxml-harness/tooling/libxml2_html.c (`YAXML_HTML_HELPER`) in yaxml-harness/tests/html_oracle.rs; html-tokenizer results replayed in tests/internal/html_events.rs. Fuzz targets html, html_events, html_fragment.
- Capabilities/reset: src/features.rs (`Feature` = `XML_WITH_*` numbers, `has`/`has_code`/`all`, `VERSION`, `LIBXML2_COMPAT_VERSION(_NUMBER)`, `check_version`). `reset`/`reset_with` on PushParser/BufferedReader/TextReader = `StreamingSession::reset` -> `Stream::recycled` -> `ParserState::recycled`/`Tokenizer::recycled`: build a fresh value and move over only emptied Vec/HashMap/String capacity (never copy a scalar; add new ParserState fields to `new` only and they reset for free). Resolver always dropped; `reset()` keeps flags+limits. Measured -13..17% on 100k tiny docs (yaxml-harness/examples/reset_bench.rs). Not done: DOM builders/Reader reset.
- Namespace errors (`ErrorKind::Namespace` = libxml2 `xmlNsErr`, docs/compatibility.md#namespace-errors) never stop a parse, strict or not: `Budget::recover` (`#[cold] #[inline(never)]`) records `Namespace` without `recovers` (`recovered` Vec always present, same 100 cap); `conclude` still returns a strict terminal error.
