# yaxml agent notes

Pure-Rust libxml2 2.15.4 rewrite. `#![forbid(unsafe_code)]`; memchr is the only library dep. Benchmarks, libxml2 differentials and the XMLTS run live in `harness/`, fuzzing in `fuzz/` (both own Cargo workspaces, never built by root `cargo test`; see Harness, Fuzz). Package = src + README (doctested via cfg(doctest)) + LICENSE-*; src must not include_str! anything outside src; keep `include` in Cargo.toml in sync. docs.rs = nightly `--cfg docsrs` -> `doc_cfg` feature labels; CI `package` job = that doc build with -D warnings + `cargo package`; release steps docs/process.md#releasing-to-cratesio. FFI bindings live in `bindings/` (own Cargo workspace + lockfile; not in the package; approved, docs/bindings.md).

## Layout
- One engine (src/parser.rs, src/tokenizer, src/stream) feeds Reader (slice), PushParser, BufferedReader, TextReader, Document (borrowed DOM), OwnedDocument (arena, `OwnedNodeId`). DTD-free input stays on the plain token loop; DTD stack = src/dtd*.
- Cargo features (README.md#cargo-features): `default = ["full"]`; core (`default-features = false`) = parsers, both DOMs+Editor, DTD+`valid`, diagnostics, save/Writer, uri, chars. Optional: `xpath` (xpath eval, xpointer, pattern), `c14n`/`xinclude`/`schemas` (xsd, relaxng, schematron, schema_types, regexp) imply xpath, `catalog`, `html`, `textreader` (implies schemas: its validator hooks), `textwriter`, `sax` (src/sax.rs = `Handler` trait driven by the slice `Reader` over `Transcoded`; declarations replayed by kind from `Reader::dtd()` after the DOCTYPE event and at the first element (external subset); `reference` skips the entity's events; `Handler::locate(&Locator)` only when the offset changes (`Sax::locate`): start tag = position-1/-2, start_document past blanks after the decl, fatal = input end unless outside-root kinds; lazy `LineIndex` behind a private `Lines` trait object since OnceCell is invariant; defaults always: crate-private flag bit `options::SAX_DEFAULTS` (1<<31, set after `check`) makes `Flags::default_attributes()` true; without NOENT `sax::unexpanded` rewrites values from `Budget::kept()` or `&`->`&#38;`, xmlns values untouched), `debug` (src/debug.rs = debugXML dumps over OwnedDocument; DTD children re-read via `save::dtd::units` with flags 0 so ATTLIST defaults keep kept forms (`stored_default(.., kept=true)`); XMLTS differential in tests/debug.rs, 8 `DIVERGENT`), `encodings` (UCS-4 + EBCDIC: src/encoding/iconv.rs generated by tooling/gen_iconv.py; cfg arms in encoding.rs `select`/`charset`/`ascii_head`, diagnostic.rs `LineIndex::new`). Gating = whole modules in src/lib.rs; without xpath an inline `mod xpath { mod tree; }` keeps `Navigate`/DOM accessors, without schemas `mod regexp { mod unicode; }` keeps the `chars` tables. Compiled-out flags are `UnsupportedOption` via options.rs `NEVER` (`XINCLUDE`, `CATALOG_PI`) and save `SUPPORTED` (`AS_HTML`); `features::TABLE` uses `cfg!`. Few call-site cfgs: owned.rs (`HtmlBuilder`, `TreeBuilder`, `HtmlMeta.decoding`, xinclude pass), diagnostic.rs (`LineIndex::html`, schema `describe`s), parser.rs (`note_catalog`, `max_events`), textreader-only helpers in buffered/stream/valid. Shared helpers (src/fallible.rs, xpath/tree.rs) are `cfg_attr(not(feature = "full"), allow(dead_code))`; everything else feature-specific gets a precise `cfg`. Tests: a file needing a feature = `[[test]] required-features` in Cargo.toml; a test in a core file = `#[cfg(feature)]` on the fn; `yaxmllint` bin needs `full`.
- `ParseOptions` (src/options.rs) is the single entry for flags (libxml2 `XML_PARSE_*` values), `Limits`, `DecodeLimits`, `base`, `Resolver`. Default = libxml2 default (entity-ref nodes kept, nothing loaded). Unimplemented flags -> `ErrorKind::UnsupportedOption`, never silently ignored.
- Config structs (every `Limits`/`Options`/`ParseOptions`/`EditLimits`/`WriterLimits`/`DecodeLimits`) are `#[non_exhaustive]` with pub fields, `Default` = `const DEFAULT`; outside the crate build via `X::DEFAULT.field(v)` chains (setters from `setters!` in src/setters.rs; list every field there, a missing one fails to compile) or field assignment; no struct literals. tests/defaults.rs pins every default: update it with any default change (docs/bindings.md#configuration-structs).
- Crate-private `Navigate` (src/xpath/tree.rs) is shared by XPath, C14N, valid, relaxng, xsd, pattern, schematron.
- Allocation failure (src/fallible.rs): `TryPush::try_push` (Vec/String), `copied`/`concat`/`cloned`/`collected`/`filled`, `Text` (sticky-refusal String for many appends: TextWriter `Machine.out`, TextReader dumps, C14N `to_string`; `finish()` -> None if refused), `Memory` (fallible `to_vec` sink; Io error = Allocation). `From<TryReserveError>` for xpath/regexp/catalog errors and xsd `TooComplex` (`Work`/`Refused`). Refusal patterns: validators replace all diagnostics with one `Code::Allocation` and ignore later events (valid/engine `refuse`, xsd/validate `refusal()` detected by first diagnostic, relaxng `Store::refused` = exhausted, schematron `refuse(&mut output)` -> Abort); schema builders report and give up on the component (xsd `Parser::add`, `Drafts::refuse/failure/refusal`, `Names.refused`; relaxng `Compiler::refused`, `Checker::room`; schematron `Parser::room/push/refuse`). Reserve before index-producing pushes (never push-then-skip: later indexing would panic). XPath sorts unstably (keys unique), `Eval::reserve(nodes, n)` = node ceiling + try_reserve, `ranked()` before key().
- Feature `allocator_api` (Rust 1.100): `OwnedDocument<A = Global>`/`OwnedNode<'d, A>`/`Editor<'d, A>`; nodes+attributes in `allocator::Vec<_, A>` (one clone of `A` each), `parse_in`/`create_in`/`allocator()`. src/allocator.rs is the only cfg switch (off = sealed stand-in, MSRV 1.97, API unchanged). Pool/ids/dtd/errors/scratch stay global. Generic consumers: `Navigate` users + Writer (`save::Walk`); `save::Tree`/`to_vec`/html/xinclude Global-only (generic public `Tree` breaks `Tree::Borrowed(..)` inference). `parse_in` rejects XINCLUDE. Keep new constructors in `impl OwnedDocument` (Global) so `OwnedDocument::parse(..)` infers. Derive Copy/Clone on A-generic views manually (derive adds `A: Copy`).
- relaxng: one `Engine<I>` (src/relaxng.rs: start/flush/text/end/finish; `wanted`/`rejection` = libxml2 innermost first message: TYPEVAL/DATATYPE/TYPECMP/VALUE/LISTEXTRA (token after last nullable prefix)/TYPE, also for attribute values; `simple` = DATAELEM/VALELEM/LISTELEM, `Frame.content` NOT_ALLOWED after) driven by the DOM walk and by `relaxng::Stream` (events; used by `TextReader::relaxng_set_schema`). `Deriver` holds `Arc<Arena>`/`Arc<Tables>` so `Stream` has no lifetime. No subtree buffering (libxml2 FullElement unneeded).
- XSD instance validation is one event engine (src/xsd/validate.rs `Validator`: start/text/end/other); tree `run` and public `xsd::StreamValidator` both feed it. `run(.., root, create)`: `validate_element` = subtree root; `validate_creating` collects `Created` defaults (attrs + empty-element text, VC_I_CREATE) then applies them through the Editor (prefix: innermost prefixed binding else `pN` on the document element; libxml2's default-ns pick diverges). Stream == DOM diagnostics is tested (tests/xsd_stream.rs, suite, tests/support/fuzz/xsd.rs). `Schema` = `Arc<Compiled>` (crate-private, fields via `schema.data`), so `StreamValidator`, `Validator`, `Engine` and `pattern::StreamMatcher` (`Arc<Stream>`, state split in `Cursor` so no per-event clone) have no lifetime. `TextReader.validators` (dtd + relaxng + xsd) is the one feeding point (`fetch`, `skip_entity`, Doctype -> `set_dtd`, `sync` after every fetched event); `xsd_set_schema`/`xsd_diagnostics`; `is_valid` = any set and none failing.
- XSD component views = src/xsd/view.rs (`Schema::element/attribute/type_definition` + sorted lists; views are `(&Schema, id)` pairs (`ElementDecl` keeps name, `final_`, resolved `head` and fixup's `members_of` = libxml2 SUBST_GROUP_HEAD iff non-empty); built-ins = ids `0..=Type::all().count()`, named but not in `global_types`). Differential tests/xsd_components.rs + harness/tooling/libxml2_xsd_components.c (`YAXML_XSD_COMPONENTS_HELPER`; replicates private `xmlSchemaItemList`/`xmlSchemaAttributeUse`/`xmlSchemaImport` to walk `attrUses` and imports). Known diffs: restricted unions list members, wildcard ns sets sorted. Attribute groups: `Compiled.attribute_groups` = fixup's `group_attrs` moved in finish (expanded, checked uses). Notations: `Compiled.notations` names only (libxml2 keeps no ids); every notation has Global id 0, so fixup's dedupe key includes `loc.node`. IDCs: `Compiled.idcs` (selector kept as `(xpath, Pattern)`) + `global_idcs`; helper mirrors private `xmlSchemaIDC`/`IDCSelect`/`QNameRef`. Particles: fixup's `particles` (put back after `content_models`) + `d.groups` moved into `Compiled`; `Term::GroupDef` reads as the group's model (libxml2 replaces refs with the model group, nested too); `view::Wildcard` serves attribute and element wildcards (`components::Wildcard` is the storage). Annotations: parse.rs `note` decides the owner as `(Loc, Annotated)` (the kind keeps a type's annotations off its synthesized sequence, which shares its Loc); fixup `annotations` imports each into one `Notes.doc` (`<annotations/>`) minus xmlSchemaCleanupDoc's blank text/comments/PIs (source+copy preorders zipped; schema docs are NOENT); `expand` starts `created = own.is_some()` (libxml2 intersects the own wildcard in place, keeping its annot). Helper prints ` note=[..]`.
- XSD content models: src/xsd/automaton.rs = libxml2 epsilon-NFA replica (determinism verdict only; order matters), model.rs Glushkov `Graph` (validation). Both quadratic for n optionals in a sequence (libxml2 too). Shared `model::Budget {work, bytes}` (`charge`/`hold`); fixup refunds the automaton's bytes after each model (`scratch`), Graph bytes accumulate. `max_model_bytes` 64 MiB = peak bound (n<=1741 optionals, 22·n² B); `Trans` is 20 B with i32/u32 fields (keep compact: transitions dominate memory).
- DTD validation is one event engine (src/valid/engine.rs `Validator`: start/text/other/flush/end; Glushkov `Model` state per open element, ID set, IDREFs checked when the root ends). Tree `engine::run` walks the tree (EntityRef = `other`: content of EMPTY; Text = flush+text so tree text nodes stay runs) and stable-sorts by a `(element ordinal, phase)` key into xmlValidateDocument preorder, rewording ContentModel; stream (src/valid/stream.rs `StreamValidator`, public) keeps push wording (`Misplaced x`/`Text not allowed`/`Expecting more children`, once per element) and document order. Root start tag is held (`Root`) until `set_dtd`/next event: the stream loads the external subset while reading it, so the DTD is complete only after that event. `set_dtd` copies until the root is checked, then only reports new `dtd.issues` (parser-time NotStandalone etc.). Empty DTD/no DTD in stream = SAX `Validation failed: no DTD found !` (tree validates against an empty DTD: the one stream/tree difference). TextReader `DTDVALID`: source built without it, then `set_flags` with it (loads like libxml2). `valid::valid_elements` (xmlValidGetValidElements) = engine `insertable`: per candidate (`Element::potential_children` = names of the printed model, first 256) a fresh Validator over parent + shallow children (entity refs entered), errors keyed at ordinal 1 only (no IDREFs); fixtures tests/fixtures/valid_elements from harness/tooling/libxml2_valid_elements.c. Stream == tree: tests/valid_stream.rs (+ `--ignored` suites and xmllint differentials), tests/support/fuzz/valid.rs.
- TextReader: `NOBLANKS` is decided at fetch with src/blanks.rs `Blanks` (areBlanks incl. the `*space=-2` rule that the DOM `xpath::tree::blanks` shares; declared content from its DTD at open; `Node.replaced` marks NOENT replacement text, never dropped), so buffered subtrees match the tree; the source never sees the flag (`streaming`). `PushParser`/`BufferedReader` apply the same core as `blanks::Filter` (holds a blank run until the next event; entity content passes; declared content via `Budget::content`, which `content::note_content` sets for every DTD-stack start tag under NOBLANKS); `Reader` rejects NOBLANKS. `set_parser_property` = `BufferedReader::set_flags` on a pristine session (resolver kept). Attribute value children (`read_attribute_value`) are `Node.parts`, split from `Budget::kept` taken right after a Start/Empty event (`Attr.position`); no kept form = one text, even empty. libxml2 quirks matched: `IsDefault` false, `Normalization` true, `Standalone` -1/-2/0/1, NodeType 6/9/11/12/13/16/17 never emitted (verified with xmllint --stream --debug; 13 because `xmlNodeGetSpacePreserve(text)` is -1). Rejected, with reasons in docs/textreader.md: CurrentNode/CurrentDoc/Preserve/PreservePattern. Errors are returned (no handlers); `line_number`/`column_number` = parsing point via `source.position()` in a caller `LineIndex`. Differential: harness/tooling/libxml2_textreader.c takes FLAGS; `noblanks_streams_match_xmllint` needs YAXML_XMLLINT.
- Walker (src/walker.rs, feature textreader) = xmlReaderWalker over `OwnedDocument`: literal port of ReadTree/NextTree/NextSibling (no text merge, childless = empty no End, `next` from last child skips parent End, node persists after EOF); accessors mirror TextReader; inner/outer via `save::to_vec`. Fixtures tests/fixtures/walker/NAME.MODE.txt recorded by harness/tooling/libxml2_walker.c (`YAXML_WALKER_WRITE=1` writes `.actual`).
- Streaming hot path: tokenizer `step` (src/tokenizer.rs) is one memchr step per lexical state (no per-byte calls; a markup prefix classifies all its available bytes in one step); `Stream::advance`/`Tokenizer::advance` are `inline(always)`, `advance_inner` scans steps then appends `buffer ++ input[..cursor]` once per call; runs <=8 B (small chunks) append via `extend(map)` (no memcpy call: libsystem memmove ~45 instr) and OR `escape::suspect` into `Tokenizer.screened`, so `validate` (inline(always)) skips `invalid_char` (memcpy path/`append_slice` clear `screened`; `release` resets it); `adopt` copies tokens <=16 B the same way (`screened_push`: buffered mixed -7.8%; 32 B regressed namespaces/text); `ready: Option<TokenKind>` + separate `span` (a packed `Option<(kind, TokenSpan)>` went through misaligned stack copies = store-forwarding stall, 7% of mixed push/7 samples); non-UTF-8 `width` out of line (`decoded_width`, else NEON constants hoisted into every call's prologue); `StreamingSession::drive_session` (DTD loop) `inline(never)` so the plain frame stays small (-4% cycles push/7); token runs append within spare capacity without the checked growth path; plain UTF-8 bypasses the decoder (`Stream::advance`). Stream `ParserState` is `lending_namespaces`: names get placeholder `LENT`, `ParserState::lend` fills them from bindings at delivery, closed scopes unwind at the next `process_token` (`settle`); DTD handover calls `stop_lending`. Perf method/table: docs/benchmarks.md (matched driver + `/usr/bin/time -l` instruction counts under host load). PushParser holds only the session (failure/finish/`max_input_bytes` live in `StreamingSession`) and the NOBLANKS filter (strict `feed` keeps its plain closure; `feed_filtered` is out of line). Callbacks are `FnMut(&Event, SourceOrigin)`: `deliver` lends the event by reference (attribute list stays `Attributes::Owned`, capacity recycled via `parser::emptied`); while lending, normalized values go to `ParserState::lent` (boxed on first use: state size taxes every slice-reader construction, 496 B cost tiny reader 9%) with `LENT_VALUE` ("\0") placeholders filled in `lend`/`lend_event` (inline(always)); namespace-declaration values are never lent; `settle` clears. Slice reader: `read_step` dispatches once on `rereads()` to `step::<REREADS>` -> `read_token::<REREADS>` (`process_token` = `read_token::<false>` for every other frontend), so strict parsing compiles without recovery checks; `normalized` is inline (no-change scan), `normalize` out of line; `delimited_body` inline(always) (constant delimiters, no memcmp); `invalid_char` <16 bytes uses a table, longer = 128/64-byte bool-fold screens (C0|`EF`) + exact `EF BF BE/BF` recheck of a hit block. Safe SIMD = `as_chunks::<N>()` + `fold(false, |a, &b| a | test(b))` (NEON cmp/orr/umaxv); intrinsics need unsafe, std::simd nightly. `escape::find_byte(bytes, from, marked, screen)` (exact test + vectorizable superset, 16-B blocks, `position` over blocks) drives `save::Out::text` (`SPECIAL` tables = same const fn `special` as its screen; non-ASCII runs in out-of-line `Out::encoded`) and `save::escape_into`; equivalence method + numbers in docs/benchmarks.md "Safe SIMD kernels". Measured dead ends (don't retry): in-place `drive_chunk` below 32 bytes (+6% instr, tails rarely hold a token), scalar loops instead of memchr on short haystacks (+2%), `inline(always)` on `process_token` (-2% instr but +6-11% cycles); `inline(always)` on `advance_inner` (-1.3% instr, +4% time); out-of-line memchr wrappers; `drive_chunk` `inline(never)` (+2% cycles push/7); local `Scan` in `advance_inner`; one-pass short tag scan; cold/`inline(never)` helpers or tail calls for recovery checks without the const generic (LLVM re-spills elsewhere, no gain); `invalid_char` table scan beyond 16 bytes (2.3x worse at 40); SWAR control screen; start tags (docs/benchmarks.md 2026-10-22): `=`-count attribute reserve, `short_value` byte table, eager `local`/no single-attr case in the duplicate check, out-of-line colon split, `[..length]` value slice, owned node reserve from a full `<` count (text +8.6%, RSS +34%; kept instead: `expected_nodes` 16 KiB sample, uncapped but `min(max_events)`, svg -3%, RSS -38%). Per-event fns must not inline once-per-document transitions: `StreamingSession::start_dtd`, `DtdSession::start_content`, `Reader::start_content`/`read_declarations` are cold+inline(never) (`read_session` = content arm only) (inlined: 18 KiB frames in `prepare_inner`/`read_session`, probed per page every event; buffered DTD -3..-5%); check frames with objdump `sub sp, sp, #0x1, lsl #12`. Lent events: `match`, not combinators, and inline(always) `parse_event`/`lend_current`/`lend` (each rewrap = an 88 B copy, some misaligned). `scan_name` = one `NAME_BYTES` pass (`:` = START|CONTINUE|COLON, last colon splits); duplicates: 1 attr no check, 2+ out of line in `resolve_attributes` (<=SMALL_ATTRIBUTES (ID, local) pairs, else sorted; inline, its array cost reader mixed +1% instr with no attributes); `resolve_attribute` skips unprefixed non-xmlns. `dom::NodeId` = NonZeroUsize index+1 (one-word links); `OwnedNodeId.slot` stays raw usize (`from_parts` total); owned `view(index)`. `publish_replacement`/`publish_physical` inline(always) (-2% NOENT DOM dtd rows); `next_stable` checks `pending.is_some()` before `take()` (-1.5-2%). PGO (docs/benchmarks.md 2026-10-22): -3..-28% trained, untrained surfaces +3-6%: binaries only, train every surface. Owned pool/`bind` copies charge `max_owned_bytes` cumulatively: changing their growth changes limit acceptance. Never write `Self { a, b: a && c, ..self }` builders: rustc 1.95/1.96 SimplifyComparisonIntegral miscompile (fixed in 1.97, the MSRV; rust-toolchain.toml pins 1.97.0) (rust-lang/rust#158206) drops `a`; check with tooling/simplify_comparison_scan.py. Exact per-feed instruction traces: lldb single-step script in docs/benchmarks.md method. rustc 1.97 emits v0 symbols (`_RNv...`): set lldb breakpoints by `nm` address, not legacy `_ZN` names. Small-chunk series 2026-10-20 (docs/benchmarks.md): 65/65 (mixed push/7 1.09, namespaces 1.05); find stalls with xctrace Time Profiler leaf addresses + `atos` (scratch method in that section), M1 push/7 is ~25% frontend-bound, so cycles != instructions. Left for namespaces: 2-3 mallocs per `xmlns` binding (`ParserState::bind` copies prefix+URI under `copying_names`, ~8% of namespaces push instr). DTD family rows (`dtd-decl/refs/nested/attrs`, `dtd`; helper profile `dtd` = NOENT): see next bullet.
- DTD content path (src/dtd_controller/content.rs, src/dtd_tag.rs): stable input (slice reader, DOMs) and entity replacement text are scanned in place by `content::scan` (no token copies; the `Work` ledger charges scanning); push reads plain UTF-8 chunks in place (`drive_chunk`). Buffered can't lend from `fill_buf` (breaks `position()` == consumed source, tests/buffered.rs) and gained <2% when tried: its gap is per-event session layering (lend/prepare/drive). Replacement tokens go through the physical path (`publish_replacement`, `ParserState.replacement`: markup errors stop instead of recovering). Each entity's text is scanned once into cached `Piece`s (memory charged as catalog storage); every reference still charges its whole expansion to the amplification/expansion ledgers (tests/amplification.rs). `Recent<T>` = 64-slot direct-mapped caches in front of the SipHash maps for entity/element lookups: unkeyed slot index, collisions only evict, so worst case = the keyed lookup; keep SipHash behind it. One start-tag path `start_element::<_, DTD>` + `TagDeclarations` (one declaration lookup per tag, unchanged values borrowed via `DtdCatalog::unchanged`, defaults appended: charge = `ElementDecl.copied` total less specified attrs, declarations walked only to copy (DTDATTR/`namespace_defaults`) or note standalone); linear duplicate/attribute scans only below small thresholds (hash past them; keep bounded, cf. adversarial_scaling). PI catalogs in content: `note_catalogs` in both publishers. In-place `content::reference` needs `;` within `token.bytes` (inclusive, = `ReferenceCursor::checked_advance` across chunks): acceptance under token ceilings is chunk-independent (tests/dtd.rs `reference_token_ceiling_is_inclusive_for_any_chunking`). Results/remaining gaps: docs/benchmarks.md "DTD-heavy parsing" + "Entity references after a DOCTYPE" (a reference ~900-1000 instr units over inline text, flat over frames/ledgers). Recorded expansions (src/dtd_controller/content/template.rs; NOENT, stable source, top-level refs): `Slot` per EntityId Unseen->Seen->recording (2nd ref) ->`Recorded`; later refs replay when `fits` (every ledger's headroom >= whole recorded cost: counters monotone within a reference, so no inner check could fail; else expand as before = same error/offset); owned charged per replayed event; origins rebased (invocation `- first + base`, physical_reference = new ref); ineligible = prefixed (non-`xml`) names, xmlns attrs, PIs, by-name nested refs, kept forms, any error/warning, owned charge without event; default ns must match incl. Cow ownership. Caps 16 KiB/recording, 1 MiB total. Entity depth and amplification need no check (fixed ceiling/empty stack; amplification ceiling = used + `left`). `record` is inline(never) on the recording path only; `replaying` checked after the frame path. Test: tests/internal/templates.rs (`TEMPLATES` cfg(test) switch, on vs off at every ceiling).
- Attribute entity refs without NOENT (libxml2 attr children): `dtd_tag::kept_form` -> `TagDeclarations::value` -> `Budget::kept()` (last start tag, by final attribute position; DOM builders drain it) -> sorted side tables `Document.kept` / `OwnedDocument.kept` (allocator Vec, pool ranges); empty = zero cost. Public `unexpanded_attribute(pos)`; `save` (`Walk::kept_form`) and yaxmllint `--xpath` write it; `attributes()` values stay substituted (XPath/valid/C14N). ATTLIST defaults carry `StoredDefault::Value.kept` (DTDATTR). Writer writes substituted. Owned `set_attribute_value` drops the form.
- Owned editing core = src/owned/edit.rs (moves, unlink/replace, set/remove_attribute, declare_namespace, set_name, set_url, compact). Invariant: attached tree namespace-consistent (each element/attr prefix resolves to its stored URI). `reconcile(root, context)` = read-only `plan` (declare (prefix,uri) on topmost element needing it, never rename; 2nd pass = same-element conflict -> `Namespace`) + quotas + reserve + commit. Structural ops plan with `context` = new parent before relinking; attribute/name ops apply, reconcile, undo (`pop_attribute`/`restore_attribute`/old name) on failure. Detached subtree = live records, root parent NONE, outside `nodes()`. Attr ranges contiguous: growing a non-tail range relocates it to the tail (garbage); never truncate the arena outside `compact` (empty ranges may point past the tail; exception: copy rollback truncates back to the pre-call length, which every older range fits). Entity-ref content is structurally read-only (`ProtectedNode`). `append_*` never merge Text; only `append_child` (xmlAddChild); 2.15 sibling inserts don't merge.
- In-context parsing = `Editor::parse_content` (src/owned/copy.rs; xmlParseInNodeContext/xmlCtxtParseContent, balanced chunk = on `root()`; `parse_external_entity` = `resolve::decode(bytes, versioned=false)` then parse_content: xmlParseCtxtExternalEntity, whose fresh ctxt has no version to mismatch). Detached result by design (names need context bindings; HTML `parse_fragment` returns a doc instead). Path: `OwnedDocument::parse_tree(.., Some(Context))` -> `Reader::in_context` (cursor 0, `ParserState::in_context`: `fragment` = Content phase never Epilog, `initial=usize::MAX` so `<?xml` is a misnamed PI, bindings seeded via `bind`); doc with DTD -> `DtdController::seeded` (catalog `seed`: entities with `input` cleared + notations, no ATTLIST: libxml2 fresh ctxt has no attsDefault) -> scratch doc (root children = content; `blanks(tree, content)` treats root as `#root`, trailing blank kept) -> `stage` into one `Staged` per top-level node + `publish(.., reconcile closure)` planning with `Some(context)`; `Target.same=true` (refs resolve). Errors `EditErrorKind::Parse(kind)`+`value_offset`; `LineIndex::content` (`Scan.content`: top-level `</`=85, no prolog/epilog, `<!DOCTYPE`=start tag). Differential harness/tests/fragment_oracle.rs + tooling/libxml2_fragment.c (`YAXML_FRAGMENT_HELPER`, `_CASES`, `_SEED`; mode W = whole-document control: divergences a whole doc shows too are counted, not failed); fuzz target `fragment` (tests/support/fuzz/fragment.rs, reuses `domedit::check`/`snapshot`).
- Copies = src/owned/copy.rs: `Editor::import(&OwnedDocument<B>, id, deep)` (xmlDocCopyNode), `Editor::copy` (xmlCopyNode, shares pool ranges: pool is append-only, nothing mutates bytes), `OwnedDocument::try_clone` (xmlCopyDoc, faithful incl. tombstones/counters). Pure `stage` (source preorder -> scratch records numbered from dest `nodes.len()`; root attrs staged last so root declarations grow the attr tail in place) then `publish` (reserve all, push unreachable, `reconcile_copy`, truncate back on failure). `reconcile_copy` = per-element `plan`, then `hoisted` seed (one decl per prefix on the root, = xmlDocCopyNode) re-planned; kept when Ok and not longer. ## Harness (`harness/`, own workspace: `[workspace]` in harness/Cargo.toml; root Cargo.toml has none)
- Separate workspace (not a root member) so root `cargo test`/clippy/lockfile never see it and its `yaxmllint` bin (built from `../src/bin/yaxmllint/main.rs` for `CARGO_BIN_EXE_yaxmllint` in tests/xsd_suite.rs) doesn't collide with core's. Dep `yaxml = { path = ".." }`; `#[path]` includes `../../tests/support/{fuzz/driver.rs (examples/fuzz_replay.rs), fuzz/text_script.rs (tests/text_writer_oracle.rs), html_corpus.rs (tests/html_oracle.rs)}`: renaming/moving those breaks harness/fuzz. Test defaults for oracle/suites = `CARGO_MANIFEST_DIR/../../yaxml-{oracle,suites}`.
- Root scripts (POSIX sh, `set -eu`, header comment = `--help`, clear `die` on missing prerequisites) source harness/lib.sh: ROOT, HARNESS=ROOT/harness, YAXML_ORACLE=../yaxml-oracle, YAXML_SUITES=../yaxml-suites (beside the checkout), FUZZ_TOOLCHAIN, CARGO_TARGET_DIR=harness/target, FUZZ_TARGET_DIR=fuzz/target, RESULTS=harness/results, CORPUS=fuzz/corpus-full if present else fuzz/corpus; `helper NAME` (compiles harness/tooling/libxml2_NAME.c against the oracle when stale -> target/helpers/NAME), `need_*`, `help_if`.
- setup.sh [oracle suites corpus] (default oracle suites): fetch+sha256+build libxml2 (CMake: static, ICONV/ICU/ISO8859X/ZLIB/PYTHON off; schematron off, so the schematron differential is skipped unless YAXML_SCHEMATRON_HELPER is set), fetch XMLTS + generate xmlconf-catalog.tsv (2586 lines) with the xmlconf_catalog helper; `corpus` clones `$YAXML_CORPUS_URL` (default github pbdeuchler/yaxml-corpus; local bare `../yaxml-corpus.git`) into fuzz/corpus-full (gitignored), warns and continues on failure.
- oracle.sh: exports YAXML_XMLLINT, YAXML_LIBXML2_SRC/_SOURCE, YAXML_SUITES, YAXML_XMLCONF and every YAXML_*_HELPER; steps core (root, `--include-ignored`, skips timing `doubling_input_does_not_quadruple_time`) / harness (`--include-ignored --skip child_`: oracle_process child stubs) / replay / structure / xmlconf; release profile with LTO off (CARGO_PROFILE_RELEASE_* env).
- pgo.sh: PGO yaxmllint (gen/use target dirs under harness/target/pgo; fixtures from examples/write_fixtures.rs; llvm-profdata from rustup llvm-tools, else xcrun). Library crate isn't PGO'd (downstream compiles it); bindings would need their own training (Go capi: link `libprofiler_builtins-*.rlib` via CGO_LDFLAGS, but the go test binary writes an empty .profraw: needs an explicit `__llvm_profile_write_file`; unmeasured).
- bench.sh: parse_benchmark with the parse_bench helper; ratio = libxml2 median / yaxml median of (parse_ns+drop_ns)/iterations; harness release profile = core's (thin LTO, 1 CGU).
- Tests building examples (`*_cli.rs`, oracle_cli) run `cargo build --example` in harness; fixtures harness/tests/fixtures (fake_*.rs, create_oracle_expected.tsv); conformance baseline harness/tests/fixtures/xmlconf-20130923-required.tsv (9,810 pairs, 1,962 IDs).
- Core keeps namespace errors without failing (`errors()`); conformance_worker (XMLTS scores namespace well-formedness), fuzz_replay (xmllint `--strict-namespace`) and parse_bench (the C helper fails on any error) count a kept error as rejection.
- CI: .github/workflows/harness.yml (oracle, fuzz-smoke = each target's binary replays `tests/fixtures/fuzz-regressions/<t>` (allocfail: sweep, `infallible-*` with MIN_SIZE=16384), coverage; checkout path `yaxml` so ../yaxml-oracle stays in the workspace).
- Harness gate (with harness/ or fuzz/ changes): `(cd harness && cargo fmt --check && cargo clippy --all-targets -q -- -D warnings && cargo test --all-targets -q) && (cd fuzz && cargo +nightly-2026-10-18 fuzz build -O) && sh -n *.sh && ./oracle.sh` (every step ok; xmlconf: required_pass_pairs=9810 required_pass_regressions=0).

## Fuzz
- `fuzz/` = cargo-fuzz crate, own workspace (`[workspace]`, dep `path = ".."`, `#[path = "../../tests/support/fuzz/driver.rs"]`). Targets `fuzz/fuzz_targets/*.rs` are thin wrappers over `tests/support/fuzz/driver.rs` `exercise_*`; fuzz logic lives in core tests, never in fuzz/. Corpus: `fuzz/corpus/<t>` = in-repo minimized (edge-only `cmin -use_counters=0`, then capped by features-per-byte; see fuzz/README.md), full corpus = separate repo -> `fuzz/corpus-full` (`./setup.sh corpus`; fuzz.sh/coverage.sh/seed.py prefer it; new inputs go there). Don't commit smoke-run additions to fuzz/corpus (`git clean fuzz/corpus`). Seeds `tests/fixtures/fuzz-seeds/` (extra read-only corpus dir). Fixed regressions: one copy in `tests/fixtures/fuzz-regressions/<t>/` (replayed by tests/fuzz_smoke.rs `fuzz_regressions_replay`); `fuzz/regressions` is a symlink to it. Unfixed findings in `fuzz/open/`.
- `allocfail` (fuzz/fuzz_targets/allocfail.rs: the only unsafe code outside bindings, `#![feature(alloc_error_hook)]`, `#[global_allocator]` over System failing the input-chosen allocation; nightly `set_alloc_error_hook` unwinds infallible failures, dropped): driver tests/support/fuzz/allocfail.rs (`allocfail_run`: `surface % 20`; 0-9 = both DOMs+try_clone+save, slice/push/buffered/text readers, owned edits/construction/import/copy, Writer, XINCLUDE, HTML parse+save; 10-18 take a second input from the first NUL piece (rest = resources): XPath, XSD (tree+stream), RELAX NG (tree+TextReader), Schematron, C14N (+node-set expr), TextWriter (replays Reader events), catalogs, regexp, HTML events; validator diagnostics checked by code *name* so the driver builds on older core for baselines; digest = DefaultHasher so the driver barely allocates; writer sinks are the Digest). Armed result == unarmed or contains `Allocation`; rerun == unarmed. Env `YAXML_ALLOCFAIL_SWEEP` (each allocation in turn), `_TRACE`, `_MIN_SIZE=n` (sweep of allocations >= n; an infallible one = crash: the audit; `infallible-*` regressions replay with 16384, older ones with SWEEP). Invariant: `Allocation` never turns into another error (Budget::recover fatal list; dtd `parse_unit`; reader `cut`; reader/session `stop` return recover's error, not the stopping one; Stream::terminal never replaces Allocation by the UTF-8 cut; TextReader text-merge keeps an Allocation `pending` like I/O (its pools refuse, the source would not repeat it); save/dtd subset re-read; nested schema/catalog parses map Allocation to the subsystem's code). Policy (docs/security.md#allocation-failure): input-sized growth fallible in every subsystem; infallible only constant/limit-bounded, one-input-item copies, or no-error-channel APIs (encode_entities, Catalog::dump/resolve, Regex::is_match, TextReader String accessors).
- Toolchain nightly-2026-10-18 (fuzz/rust-toolchain.toml). Coverage: `./coverage.sh` replays every corpus dir + seeds through each target -> per-target lcov unioned by `fuzz/coverage_merge.py` (multi-object llvm-cov undercounts). Campaign flags: `-fork=1 -timeout=2`.
